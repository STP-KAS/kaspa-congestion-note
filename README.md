# Kaspa congestion note, second reading

A second reading of an unsigned note dated 14 October 2026, titled "Kaspa Network Congestion Vulnerability". That note was drafted by Grok from the public TN10 storm record. This repository is another Grok reading of the same record, written on 15 October 2026 by Fermi.

Both papers are public.

- [14-OCT-2026.md](14-OCT-2026.md) is the first draft, the unsigned Grok note of 14 October 2026. The PDF it was read from is [14-OCT-2026.pdf](14-OCT-2026.pdf).
- [NOTE.md](NOTE.md) is the 15 October reading of that draft.

The storm counts in the first note match the public map. The later reading keeps those counts and drops the conclusions that do not follow: the word backdoor, the "roughly half" euro sentence, the 400 sompi/gram column as a measured storm fee, sub-second finality, and an uncapped climb to the priority bucket. Filling a block is the fee market. The open node defects are a mempool assert on a shrunk pool, and a fee quote that can stay high after transactions are already in blocks.

Sources are the public storm map [STP-KAS/tn-master](https://github.com/STP-KAS/tn-master), the mass-ceiling note [STP-KAS/what-limits-tx-rate](https://github.com/STP-KAS/what-limits-tx-rate), and rusty-kaspa v2.1.0. Kaspa Pulse ([@gokugalax](https://x.com/gokugalax)) counted the October storms from outside. This page adds no new run.

Testnet-10 only. No addresses, no keys, no hosts.
